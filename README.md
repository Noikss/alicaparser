# Парсер комментаторов Telegram-каналов

Telegram-бот: принимает список каналов, собирает всех, кто оставлял комментарии,
и отдаёт по каждому каналу готовый xlsx — одна строка на человека.

## Что умеет

- Вход в аккаунт по QR-коду (без ввода номера и кода)
- Полная история канала — от первого поста до последнего
- Дедупликация по Telegram user id: один человек = одна строка
- Колонки «Кол-во комментариев» и «Дата первого комментария»
- Подгрузка «О себе» (bio) отдельным запросом
- Быстрый режим: читает группу обсуждений целиком вместо запроса на каждый пост
- Устойчивость к флуд-лимитам: ждёт и продолжает с места остановки
- Файл приходит после каждого канала — при сбое прогресс не теряется

## Установка

```bash
pip install -r requirements.txt
```

Создай файл `.env` по образцу `.env.example`:

```
BOT_TOKEN=токен от @BotFather
API_ID=id с my.telegram.org
API_HASH=hash с my.telegram.org
```

Запуск:

```bash
python tg_bot.py
```

## Как пользоваться

1. `/start` — бот пришлёт QR-код
2. Отсканируй его: Telegram → Настройки → Устройства → Подключить устройство
3. Отправь боту `.txt` со списком каналов (по одному на строку)
4. Забирай xlsx по мере готовности каналов

Команды: `/status` — состояние, `/clear` — сброс сессии и памяти.

## Настройки

В начале `tg_bot.py`:

| Параметр | Что делает |
|---|---|
| `POSTS_LIMIT` | 0 — вся история; число — только последние N постов |
| `FETCH_BIO` | `False` ускоряет парсинг, но колонка «О себе» будет пустой |
| `FAST_MODE` | `True` — читать обсуждение целиком (быстро). `False` — по постам |
| `LOCAL_TZ` | Часовой пояс для дат в таблице |
| `IDLE_DISCONNECT_MINUTES` | Через сколько минут простоя отключать клиент |

## Требования к серверу

Парсинг больших каналов — это часы работы и заметный расход памяти
(pandas + накопление данных по людям). Тариф со 128 МБ RAM для этого мало.
Рекомендуется от 512 МБ, лучше 1 ГБ.

Каталог `sessions/` должен переживать перезапуски, иначе после каждого
рестарта придётся заново сканировать QR-код.

## Безопасность

`.env` и `sessions/` в репозиторий не попадают — они в `.gitignore`.
Файл сессии даёт полный доступ к аккаунту Telegram, его нельзя никуда выкладывать.
